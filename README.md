# 🛡️ RAKSHITA

### Wear. Detect. Protect.

RAKSHITA is a wearable safety and emergency response system that connects a smart bracelet with a mobile app to monitor health and activity signals, detect potential accidents, track location, and trigger alerts to trusted contacts during emergencies.

## 🚨 Problem

People may not receive timely help after accidents or sudden emergencies because their condition and location are not detected or communicated quickly.

## 💡 Solution

RAKSHITA combines a wearable device and mobile application to detect potential emergencies, share the user's location, and initiate an emergency alert workflow.

## ✨ Key Features

- ❤️ Heart-rate monitoring
- 🫁 SpO₂ monitoring
- 🚶 Activity/step tracking
- 📍 Location tracking
- 🚨 Accident/emergency detection
- 👨‍👩‍👧 Trusted-contact alerts
- 🏥 Emergency response workflow
- 📱 Mobile dashboard
